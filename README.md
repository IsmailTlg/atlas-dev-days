Atlas Dev Days

Site vitrine de la conférence Atlas Dev Days, un événement de deux jours pour les développeurs web au Maroc. Le site présente le programme et les intervenants, et permet de s'inscrire en ligne.

Réalisé en HTML5 et CSS3, sans framework ni JavaScript.
